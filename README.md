# LocalDock — سحابتك الشخصية المحلية

> **LocalDock makes local networking feel invisible.**
> حوّل أي كمبيوتر إلى سحابة شخصية خاصة تعمل داخل شبكتك المحلية — بلا Cloud، بلا حسابات، بلا تعقيد.

```text
أضف مجلدًا
      ↓
اضغط Share
      ↓
يصبح متاحًا فورًا على الهاتف والأجهزة الأخرى
```

LocalDock ليس أداة نقل ملفات ولا مدير NAS. إنه **منتج واحد بفلسفة واحدة**: تجربة شبيهة بـ Google Drive/Dropbox، لكن الملفات تبقى فعليًا على جهازك ولا تخرج إلى الإنترنت أبدًا.

## ما الذي يعمل الآن؟

| الميزة | الحالة |
|---|---|
| لوحة تحكم حية (أجهزة، مساحة، سرعة النقل، نشاط) | ✅ عاملة |
| مشاركة مجلدات بثلاث نقرات + صلاحيات لكل مشاركة | ✅ عاملة |
| مستعرض ملفات (Grid/List، بحث، ترتيب، تحديد متعدد، معاينة صور/فيديو/PDF/نص) | ✅ عاملة |
| محرك نقل مجزّأ 4MB مع **استكمال فعلي** وإيقاف/متابعة/إعادة | ✅ عاملة |
| تحقق سلامة SHA-256 (رفعًا وتنزيلًا) | ✅ عاملة |
| تنزيل بـ HTTP Range (قابل للاستكمال + تشغيل فيديو بالتقديم) | ✅ عاملة |
| اقتران أجهزة بـ QR + كود أحادي الاستخدام (TTL 5 دقائق) | ✅ عاملة |
| إدارة أجهزة موثوقة + إلغاء فوري | ✅ عاملة |
| استضافة مواقع ثابتة على `/sites/{slug}/` لكل الشبكة | ✅ عاملة |
| روابط ضيوف `?s=slug` بلا اقتران | ✅ عاملة |
| وضع داكن/فاتح + تجاوب كامل مع الجوال | ✅ عاملة |
| إشعارات، حالات فارغة، Onboarding لأول تشغيل | ✅ عاملة |

### ما يتطلب أدوات بناء خارج هذه البيئة؟

هذه النسخة هي **نواة المنتج كاملة** (السيرفر + Web Client من الدرجة الأولى، وهو قناة الوصول الفورية للمواصفات §33). الأغلفة الأصلية تُبنى فوق نفس السيرفر دون تغيير أي منطق:

- **Windows App — جاهز داخل المستودع (`src-tauri/`)**: غلاف Tauri v2 كامل — System Tray (§19) مع الإغلاق إلى الخلفية، Start with Windows (§20) عبر سجل ويندوز الحقيقي، منتقي مجلدات أصلي بدل متصفح الخادم، إعلان mDNS/`localdock.local` (§6)، منفذ ذكي بلا تصادم، وبيانات المستخدم في `%APPDATA%\LocalDock`. البناء على ويندوز بأمر واحد `bun run build:windows`، أو مؤتمت عبر GitHub Actions — كل التفاصيل في `docs/WINDOWS_APP.md`.
- **Android App**: عميل Kotlin/Compose يتصل بنفس الـ API — الاقتران والرفع والتنزيل والاكتشاف كلها واجهات HTTP موثقة في هذا المستودع. بديل فوري الآن: **أي هاتف يفتح رابط السيرفر من المتصفح** يحصل على نفس التجربة (PWA-ready).

## التشغيل السريع

```bash
git clone <repo>
cd localdock
bun install          # أو npm install
bun run dev          # لا خطوة إعداد إضافية — لا قاعدة بيانات ولا مفاتيح
bun run build:windows   # على ويندوز: مثبّت NSIS + نسخة محمولة
```

افتح `http://localhost:3000` — سيأخذك Onboarding من 60 ثانية: اسم → مجلد أول → QR للهاتف.

### بناء الإنتاج

```bash
bun run build        # standalone build جاهز للتشغيل
bun run start
```

### الاختبارات

```bash
bun test tests/unit            # 29 اختبار وحدة (أمان المسارات، المدى، التطهير...)
bun tests/smoke.mjs http://localhost:3000   # 56 اختبار تكامل ضد سيرفر حي
```

اختبارات التكامل تغطي: حدود المصادقة، الصلاحيات، traversal، الرفع المجزّأ، **الاستكمال بعد انقطاع محاكى**، تطابق SHA-256، Range، التعارضات، الاقتران والإلغاء، الاستضافة، والطلبات المشوهة.

## بنية المستودع

```text
src/lib/localdock/        ← نواة المنتج (خالية من أي UI)
  paths.ts                ← حاجز المسارات الآمن + تطهير الأسماء (الملف الأخطر)
  registry.ts             ← السجل: إعدادات، مشاركات، أجهزة، أكواد اقتران، نشاط
  uploads.ts              ← محرك الرفع: جلسات، كتابة موضعية، SHA-256، GC
  files.ts                ← تصفح/بحث/قياس + بث Range
  auth.ts                 ← Owner / Device / Guest + مصفوفة الصلاحيات
  static-site.ts          ← خدمة المواقع المستضافة
  seed.ts                 ← بيانات أول تشغيل حقيقية
  client/                 ← API client + محرك النقل في العميل
src/app/api/              ← 25+ مسار REST
src/components/localdock/ ← واجهة SPA كاملة (7 شاشات)
tests/                    ← وحدة + تكامل حي
docs/                     ← المعمارية، الأمان، دليل المستخدم
```

## الفلسفة

- **Local-first**: لا حسابات، لا سحابة، لا تتبع، يعمل بلا إنترنت إطلاقًا.
- **Safe by default**: مشاركة جديدة = Read Only + بلا ضيوف. كل شيء آخر قرار صريح منك.
- **التعقيد للتقنية، البساطة للإنسان**: لن ترى IP أو منفذًا أو بروتوكولًا في الواجهة الأساسية — كل ذلك مخبأ في Settings → System لمن يحتاجه.
- **لا مزايا وهمية**: كل زر في المنتج يعمل فعليًا، وكل ادعاء مُختبر باختبار.
